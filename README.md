# feature-selector

A from scratch implementation of Forward Selection and Backward Elimination feature selection algorithms written in C++ for Intro to Artificial Intelligence Fall 2024

<br/>

## Compile & Run
```bash
cd feature-selector
cmake -B build
cd build
make
./bin/feature-selector
```
<br/>
